Project: IoT-Based Automated Fingerprint Vehicle Access and Security System

Overview:
A smart vehicle security system using ESP32 and fingerprint authentication for keyless vehicle access.

Main Features:

🔐 Fingerprint-based authentication
📍 GPS-based location monitoring
🌐 IoT-based security alerts
⚠️ Unauthorized access detection
🔄 Adaptive Risk-Based Authentication
🚗 Relay-based vehicle access control

Novelty:
The system changes the authentication level based on risk:

Low Risk → Fingerprint
Medium Risk → Fingerprint + Owner Approval
High Risk → Fingerprint + OTP

Technology: ESP32, Fingerprint Sensor, GPS, OLED, Relay, Buzzer, IoT.

Domain: IoT & Embedded Systems / Smart Vehicle Security.
